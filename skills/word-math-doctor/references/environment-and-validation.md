# Environment and validation

## 能力层级

- **层级 0**：可读取 docx/docm 并做结构诊断；只能交付疑点清单。
- **层级 1**：可生成作者裁定清单；仍不证明已经写入 OMML。
- **层级 2**：可在明确范围内写入或修复 OMML，并另存输出文件；必须以受审核的 repair plan 限定变更，且验证原稿未写入、计划项目逐项匹配、非目标 ZIP 部件保持不变。带编号独立公式还必须验证中心/右侧制表位，而不能只检查 OMML 数量。
- **层级 3**：除层级 2 外，还可渲染、重新打开保存、检查关键页面并由独立工具复核。

## 最低验收

修复前后保存审计结果与 repair plan；比较目标范围内的结构信号；确认非目标正文、表格、图片与批注没有意外变化；报告无法验证的项目。对独立公式，检查公式对象、两个制表符、居中制表位及右对齐制表位是否都存在。OOXML 定位器不是 Word 页码，渲染页码只能由实际渲染结果给出。

不要把环境无法执行的步骤写成已经完成。

## 当前修复边界

docx/docm 可只读扫描；修复脚本仅支持 docx。只序列化已授权段落并替换原 document.xml 中的对应字节范围；根命名空间声明、非目标段落及其他 ZIP 部件保留原字节。行内公式前后 run 保留属性。目标含书签、域、批注、修订、超链接、已有 OMML 或嵌套结构时拒绝；跨段书签/批注/域范围内同样拒绝。

display 只支持显式节几何、单栏、无非零缩进且无既有制表位的水平正文。旧计划的固定制表位不符合实际版心时会被拒绝。报告始终给出 `word_open_save_verified: false`；脚本不会填写未经执行的 Word 验收结果。

## Word 侧验收

1. 用 Microsoft Word 打开修订稿，确认没有内容修复提示。
2. 进入关键公式的编辑器，确认结构可编辑且数学含义未变。
3. 检查版心、编号正体和字体字号，特别检查长公式碰撞、行高裁切及跨页。
4. 另存验收副本，关闭并重开，记录 Word 版本与结论；保留脚本原始输出供比较。LibreOffice 仅辅助验证。
