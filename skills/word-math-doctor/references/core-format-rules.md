# Core format rules

将数学格式视为项目或期刊模板的约定，而不是本 Skill 的固定偏好。

## 处理原则

- 保留数学含义和作者已确认的符号语义；不因格式统一而改变对象、索引或运算范围。
- 只有在项目规则明确时，才统一函数正体、变量斜体、向量或矩阵字形、行内与独立公式、编号和标点。
- 通过邻近同类公式和明确模板判断一致性；不能从孤立表达式推断时，列入作者裁定。
- 中文标点、导数记法、统计量、变量命名和日期下标均以本文档既有规则为准。

## 带编号独立公式

- 公式主体和编号是两个版式对象：公式在段落可用宽度的视觉中心，编号右对齐；编号使用半角括号和阿拉伯数字，例如 `(1)`，除非项目模板另有规定。
- 使用 Word 段落制表位或已存在的等价模板结构实现“居中公式 + 右侧编号”。不得用连续空格、手工字符间距或把编号并入公式对象模拟对齐。
- 修改独立公式前先确认段落是否含有分节、缩进、表格单元格、域代码或既有制表位。无法安全保留这些条件时，列为人工处理项。
- 化学式默认仍是正文文本，不因带下标就自动纳入独立数学公式规则。

## 推荐裁定字段

编号及其括号使用正体普通文本，字体和字号继承原编号 run 及其文档样式；不得根据变量斜体将编号也设为斜体。作者提供明确模板时，可在 display 操作指定 `number_style: {"font": "Times New Roman", "size_half_points": 24}` (12 pt)。这不是所有论文的默认规则。

测试用学术模板采用宋体 12 pt、Times New Roman 12 pt 和 Cambria Math，这是可复现测试条件，并非所有期刊统一要求。当前脚本只自动布局显式节几何、无非零缩进的单栏水平正文；不同页边距的普通分页节可分别计算。已有制表位、连续分节、表格、文本框、镜像页边距和装订线会被拒绝。制表位在版心内不等于公式实际宽度合适，长公式碰撞和行高裁切仍须 Word 复核。

记录原表达、目标表达、适用范围、依据、是否改变数学含义以及作者确认状态。不要把任何特定论文、变量或缩写当作默认规则。
