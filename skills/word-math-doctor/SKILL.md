# Word Math Doctor

## 目标与边界

将已明确授权范围内、确有处理必要的数学表达式规范化为可编辑的 Word 原生 OMML，同时保护数学含义、正文、表格、图形、批注和版式。

不得猜测变量含义、补写缺失公式、把公式图片 OCR 后静默替换、仅靠字体伪装数学结构，或在未获授权时扩大处理范围。文档没有提供可验证依据时，保留原状并列为待作者确认项。

## 先确定任务层级

- **层级 0：结构诊断**。只读扫描与疑点清单；不改原稿。
- **层级 1：作者裁定**。整理位置、原表达、建议处理和待确认的数学含义。
- **层级 2：限定修复**。仅处理作者已确认的项目或明确指定范围；另存输出文件。
- **层级 3：高保证规范化**。在具备 Word/OMML 写入、渲染、重新打开保存和独立复核能力时，执行全文或授权范围的规范化。

层级 0 不承诺公式转换；层级 1 不等于已生成 OMML；层级 2、3 必须先确认可用工具和备份方案。

## 工作流

1. 明确输入文件、输出文件、处理范围、目标层级和不可修改区域。范围可由页面、章节、表格、批注、文件部件或作者提供的定位器界定；不要自行扩大为全文。
2. 先保存原件副本并做只读审计。可使用 scripts/scan_docx_math.py 识别 OMML、普通上下标、可见 LaTeX、批注、表格与嵌入对象等结构信号。
3. 输出待确认清单。每项记录稳定定位器、原表达、疑点类别、证据、建议处理与作者裁定。不要把 OOXML 段落序号或启发式锚点称为 Word 页码。
4. 将已裁定项目写成 repair plan，再执行修复。优先使用 `scripts/repair_docx_math.py`，而不是让 Agent 临场手写 OOXML。每项必须给出段落定位、完整的 `expected_text` 和显式公式结构；输入内容不匹配时，脚本必须停止。仅改变已授权项目；任何不确定的数学语义、符号大小写、函数正体、索引层级、分式范围或编号规则都保留并提问。
5. 对带编号的独立公式，使用居中制表位承载公式、右对齐制表位承载编号。按所在节的页面宽度减去左右页边距计算版心，不得套用固定制表位。display 必须显式给出 `source_formula`，原段落只可包含公式、间隔空白和编号。复制原编号 run 的字体、字号和字符样式并设为正体；仅按作者提供的模板用 `number_style` 覆盖。不得用长空格推位或把编号并入公式对象。当前脚本仅处理普通纯文本正文；表格、非零缩进、分栏、已有制表位、域、书签、批注或修订等复杂目标会拒绝，交给 Word/人工处理。
6. 另存修订稿并验收：重新扫描、比较结构计数，验证目标段落外 XML 字节及其他 ZIP 部件未变，检查行内公式前后字符格式和独立公式制表位。渲染关键页面并在 Microsoft Word 中打开、编辑公式、另存和重开；LibreOffice 仅作辅助。脚本不测量公式实际宽度，不能保证长公式不与编号碰撞；未做 Word 验收时明确标为待验证。

## 格式判断

将样式视为文档或期刊模板的属性，而不是固定偏好。只有在模板、上下文或作者明确规定时，才统一函数正体、变量斜体、向量/矩阵字形、标量与向量符号、行内与独立公式间距、编号和标点。中文排版、导数写法和符号命名都应遵从项目现有的一致规则。

对每个疑点至少区分：数学含义是否明确、是否必须转为 OMML、是否在授权范围内、能否在当前环境验证。仅因文本使用上标、下标、反斜杠或 Cambria Math 并不足以证明应转换。

化学式默认保留为可编辑的 Word 文本(包括普通下标或 Unicode 下标)，不视为数学转换候选；只有作者明确要求统一化学排版，且给出适用范围与目标格式时，才另行处理。不要为了提高“转换数量”而把 `H₂O`、`CO₂` 等一律转为 OMML。

## 隐私与审计

默认审计输出不得包含源文件路径、正文片段或候选公式附近文本。只有在用户明确要求、且审计文件不会公开分享时，才启用扫描器的 --include-paths、--include-snippets 等诊断选项。不要把原稿、批注、审计 JSON 或截图提交到公开 Issue、Pull Request 或聊天记录。

## 参考资料

- 处理前查阅 references/environment-and-validation.md，判断当前环境可达到的验收层级。
- 需要统一表现形式时查阅 references/core-format-rules.md；以项目模板为准。
- 遇到失败、歧义、图片公式或不完整证据时查阅 references/failure-modes.md。
- 仅当项目另有明确符号约定时，使用 references/symbol-registry.md 记录该项目的符号；不要把某一份旧文稿的变量表复用于新文稿。
- 使用 templates/ 中的任务单、裁定清单和修改记录模板交付可复核结果。
