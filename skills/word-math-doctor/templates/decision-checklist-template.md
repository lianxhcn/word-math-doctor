# 公式裁定清单模板

| 序号 | 页码与位置 | 原稿显示或现象 | 疑点说明 | 建议正确写法 | 表示形式 | 判断依据 | 置信程度 | 作者裁定 |
|---:|---|---|---|---|---|---|---|---|
| 1 |  |  |  |  | OMML / 语义预览 |  |  |  |

使用说明：

- 若 checklist 交付为 `.docx`，且「表示形式」为 OMML，则「建议正确写法」单元格必须包含真正的 Word 原生 OMML 对象。
- 若 checklist 交付为 Markdown、HTML 或纯文本，「建议正确写法」只是线性或 LaTeX 语义预览，必须写为「语义预览」，不得称为已生成 OMML。
- 对无唯一答案的项目，在「建议正确写法」中列出候选写法，在「作者裁定」中要求确认。

裁定建议用语：

- 成立，按建议修改；
- 不成立，不要改动；
- 成立，另改为……；
- 需全文同步修改；
- 已手动处理，不再改动；
- 暂不确定，保留原文。
